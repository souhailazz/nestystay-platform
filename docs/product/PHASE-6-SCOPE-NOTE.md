# Phase 6 scope note

Phase 6 is intentionally separated from the signed Phase 5 web deliverable. The agreement describes responsive web first and mobile app work later. Phase 6 may add native iOS/Android clients, push notifications, offline gate workflows, richer accounting exports, and provider-specific production hardening after the Phase 5 web/API contract is accepted. None of those later-phase items are silently used to fail M1–M5 contractual functionality.
