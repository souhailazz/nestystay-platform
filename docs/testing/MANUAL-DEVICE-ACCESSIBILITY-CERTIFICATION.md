# NestyStay manual, device and accessibility certification

This checklist must be executed by a human tester. Automated browser tests do not satisfy these checks.

## Desktop/tablet/mobile

- [ ] 100% browser zoom and normal desktop layout.
- [ ] Tablet navigation, tables/cards, dialogs and dashboards.
- [ ] Mobile booking sheet, checkout, forms, tables/cards and PM operations.
- [ ] No horizontal-only workflow where a card/action layout is required.
- [ ] Loading, empty, error and retry states are understandable.

## Keyboard and focus

- [ ] Complete login, Explore search, booking and payment with keyboard only.
- [ ] Dialog traps focus and Escape closes it.
- [ ] Focus returns to the triggering control after closing.
- [ ] SPA navigation moves focus to the new page heading.
- [ ] Error and status messages are announced.

## Screen reader and visual modes

- [ ] Screen-reader navigation on Explore, property detail, booking and Trips.
- [ ] Screen-reader navigation on badge/admin, wellness, directory/QR and PM routes.
- [ ] Reduced-motion preference removes nonessential motion without losing meaning.
- [ ] Forced-color mode preserves focus, status, errors, buttons and badge meaning.
- [ ] Zoom review at 200% and 400% where applicable.

## Physical device workflows

- [ ] Android browser QR camera permission granted/denied/unavailable.
- [ ] iPhone browser QR camera permission granted/denied/unavailable.
- [ ] Valid, invalid, expired, revoked and wrong-property QR scans.
- [ ] Officer camera/photo upload and recovery.
- [ ] Document upload from a real phone.
