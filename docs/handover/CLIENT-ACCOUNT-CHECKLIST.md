# Client account checklist

- [ ] Domain registrar and Cloudflare account owner
- [ ] VPS provider, region, monthly limit and emergency contact
- [ ] PostgreSQL/Redis/object-storage backup owner
- [ ] Brevo organization, verified sender/domain and API key owner
- [ ] Zoho or Google Workspace decision and mailbox list
- [ ] Stripe live account, webhook secret and payout owner
- [ ] Alibaba eKYC production account, callback/signature owner and retention approval
- [ ] Optional SMS/push/maps/Stripe Connect decision
- [ ] Off-server backup destination and restore operator
- [ ] Security incident contact, maintenance window and release approver

Credentials are exchanged through the client's password manager or secret manager, never by commit, ticket or chat.
